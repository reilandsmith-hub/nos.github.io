PlayStation 1 Web (mednafen_psx_hw core via EmulatorJS)

The core requires a real PS1 BIOS. It is a Sony-owned file: dump it yourself from your own console; we do not distribute it or link to it here.

Multi-track (.cue + multiple .bin files): select or drag the .cue together with all of its .bin files at once — they are automatically packed into an in-memory zip before being passed to the emulator.

Analog sticks: "Enable Analog Sticks" shows two draggable circles (left/right). When released, the stick returns to the center. If your game requires "analog mode," enable it from the emulator menu (Control Settings) or with the game's ANALOG button if it provides one in software.

Memory Card: the emulator menu (gear icon) has buttons to download/upload the save file (.srm), in addition to automatic saving in the browser — so you can take your memory card to another PC or browser.

Changing keys: with the game loaded, move the mouse over the screen, open the emulator menu (gear icon) → Control Settings.

On-Screen Controls: "Show On-Screen Controls" overlays a transparent digital pad on the game screen. It remains visible in fullscreen.

2x Speed: the "x2 (Fast Forward)" button toggles fast-forward with one click.

Button Size: "Larger Buttons +" and "− Smaller Buttons" adjust the digital pad.
